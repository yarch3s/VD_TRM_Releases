# VD TRM Formatter

Программа для оформления документации поставщика по проекту LNG3 (СТДО): пакеты TRM, титульные листы, содержание,
штампы с подписями, учет в VDR и реестрах корреспонденции. Разработка отдела прикладного ИИ и автоматизации
процессов, **для сотрудников отдела**.

Здесь лежат только готовые выпуски программы. Исходников, базы и данных проекта в этом репозитории нет.

## Установка

1. Откройте [последний выпуск](https://github.com/yarch3s/VD_TRM_Releases/releases/latest) и скачайте
   `VD_TRM_Setup_X.Y.Z.exe`.
2. Запустите файл. Права администратора не нужны: программа ставится для вас в
   `%LOCALAPPDATA%\Programs\VD TRM Formatter`, ярлык появится в меню «Пуск» (и на рабочем столе, если отметить).
3. Если Windows покажет «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом
   случае». Так бывает с программами без платной цифровой подписи; файл можно проверить (см. ниже).
4. При первом запуске программа попросит указать папку базы: папку с разделами `1_Стандарт`, `2_Данные проекта`,
   `3_Реквизиты`. Базу выдают в отделе. Результаты сохраняются в `Документы\VD TRM Formatter\Результаты`.

## Обновление

* Само: когда выходит новая версия, в шапке окна появляется «Вышло обновление: версия X.Y.Z». Нажмите «Скачать и
  установить»: программа скачает установщик, проверит его, обновится и откроется снова. База, результаты и
  настройки не меняются. «Что нового» покажет список изменений.
* Вручную: скачайте новый `VD_TRM_Setup_X.Y.Z.exe` и запустите его поверх установленной программы.
* Проверить: в программе «Настройки», «О программе», «Проверить обновления».

## Переносная версия

`VD_TRM_portable_X.Y.Z.zip`: программа без установки. Распакуйте в папку с коротким путем (например `C:\VD_TRM`) и
запустите `VD_TRM\VD_TRM.exe`. Обновляется так же, из окна программы.

## Проверка файла

В каждом выпуске есть `SHA256SUMS.txt` с контрольными суммами. Проверка в PowerShell:

```
Get-FileHash .\VD_TRM_Setup_X.Y.Z.exe -Algorithm SHA256
```

Сумма должна совпасть со строкой файла в `SHA256SUMS.txt`. Программа при обновлении проверяет это сама.
